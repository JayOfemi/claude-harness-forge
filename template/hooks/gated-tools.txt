# Non-git tools the git gate also stops for review. One entry per line;
# everything after a # is a comment. Two shapes:
#   <cli>               every invocation is gated (deploy CLIs)
#   <cli>: word word    gated only when an argument equals one of the words
# Matching is by exact argument token and deliberately coarse; this file is
# a speed bump for "an agent is about to ship or destroy something", not a
# sandbox. The gate always covers git itself, with or without this file.
# Entries for tools you do not have installed match nothing and are safe to
# keep. Trim what you like, add your own stack's tools. An empty or deleted
# file means the gate covers git only.
