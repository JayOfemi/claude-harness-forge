# Dump

The ONLY sanctioned dump ground (constitution rules 8-9). Drop rule: prefix the file with `YYYY-MM-DD-`, and add a bullet to `Agents/TODO/YYYY-MM-DD.md` saying what it is, so it gets triaged. Nothing may cite a `Dump/` path as a durable location. The housekeeper role triages periodically; anything still here after triage gets routed to its real home or deleted.
